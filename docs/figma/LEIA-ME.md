# Telas exportadas do Figma

Referência de design usada para comparar o que foi implementado com o que foi
projetado. Exportar da página **Versão Final** do arquivo ParaisoFeldal.

- **Telas individuais**: selecionar tudo (Cmd+A) e exportar em PNG 2x.
- **Fluxo**: uma imagem da página inteira, com as setas entre as telas.

O nome do arquivo não precisa ser bonito — os frames saem como "Android Compact - 33"
e afins, e dá para identificar cada tela pelo conteúdo.
